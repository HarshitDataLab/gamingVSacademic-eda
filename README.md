# 🎮📚 Gaming vs Academic Performance Analysis

### 📌 Project Overview

This project explores the relationship between students' gaming habits and their academic performance using Python-based Exploratory Data Analysis (EDA). The objective is to identify patterns, trends, and potential correlations between gaming behavior, study habits, lifestyle factors, and academic outcomes.

### 🎯 Objectives

* Analyze how gaming duration impacts academic performance.
* Examine the relationship between study hours and grades.
* Explore lifestyle factors such as sleep, diet, and social media usage.
* Identify trends among different student groups.
* Generate actionable insights through data visualization.

### 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

### 📂 Dataset Features

The dataset includes:

* Gaming Hours per Day
* Study Hours per Day
* Academic Scores / GPA
* Sleep Duration
* Dietary Habits
* Social Media Usage
* Gender
* Age Group

### 🔍 Exploratory Data Analysis

#### Data Cleaning

* Handled missing values
* Checked for duplicates
* Verified data types
* Performed preprocessing

#### Analysis Performed

* Distribution of Academic Scores
* Gaming Hours vs Academic Performance
* Study Hours vs Academic Performance

#### Visualizations

### 📊 Key Insights

* Moderate gaming may not significantly impact academic performance.
* Excessive gaming hours often correlate with lower academic scores.
* Students with balanced study and gaming habits tend to perform better.
* Sleep duration shows a noticeable relationship with academic outcomes.
* Healthy lifestyle habits are associated with improved academic performance.
